# Characters belong to Accounts; each Campaign holds its own progress

A Character is owned by an Account and can play in several Campaigns. Identity, Portrait, build and Backstory live on the Character; level, hit points, inventory, spells and history live on a Campaign Character, one per Campaign, created through an approved Join Request at the Campaign's starting level. Edits to the identity flow to every Campaign Character; play state never crosses Campaigns. This replaces Characters that existed only inside one Campaign, so players keep one hero across tables without a one-shot overwriting their main game.

## Consequences

Existing Characters split into a Character and one Campaign Character by migration. Rules that read a "character" read the Campaign Character, with the Character's identity joined in.
